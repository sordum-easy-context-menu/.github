# Easy Context Menu - Add or Remove a Few Right-Click Commands

## Product Snapshot

The right-click menu is a short list that became a long one. Easy Context Menu shows categories for the desktop, drives, folders, and files, with boxes for commands the tool knows how to add and for extra items it can take away. You apply the change, the menu refreshes, and you can restore a previous state if the result is worse.

This is a preference editor. It is not a shell-extension debugger. If Explorer crashes on right-click, disable handlers in a shell-extension viewer first. Come here when the menu works and simply contains the wrong set of words.

## Add Sparingly

| Addition | Worth it when | Skip it when |
|---|---|---|
| Restart or shutdown on the desktop | You actually use it weekly | You already have buttons you hit by accident |
| Copy path | You paste paths into tickets | The menu is already tall |
| God-mode or control-panel jumps | You administer this PC | It is a relative's machine and the item will confuse them |
| Ownership or attribute tools | You understand the warning | You do not need a faster way to break permissions |
| Anything you cannot explain | Never | Always |

Every added line is a line someone can click. On a shared PC, prefer removing junk over adding power tools.

## Remove Carefully

Vendor items in the "extra" list are the ones people want gone: obsolete compress commands, cloud shortcuts, editor trials. Uncheck one, apply, and look at a real file. If the command was the only way you open a project, put it back. Uninstalling the parent program is still the cleaner fix when you do not want the software at all. Hiding the menu item leaves the program installed.

Do not clear every box in a category because the window looks like a checklist of sins. Windows commands you do not recognize may be how a feature opens. Apply a small diff.

## Steps

1. Right-click once and name the item you want added or removed.  
2. Open Easy Context Menu and find that item in the matching category.  
3. Change only that item.  
4. Apply and test the same right-click.  
5. Use the tool's restore if the menu lost something you needed.  
6. Leave shell extensions alone unless this editor actually lists them.

## Requirements

| Item | Expectation |
|---|---|
| OS | Windows versions Sordum supports |
| Rights | Administrator for machine-wide menu changes |
| Backup | The built-in restore, used before a large edit |
| Scope | Menu items the tool knows, not every COM handler |
| Habit | One change at a time |

## Fits

People customizing their own desktop, and a technician removing one obvious leftover command. A poor fit for a crashing Explorer, for file-association repairs, and for a locked-down work PC where menu policy will overwrite you. A poor fit for "more productivity" in the form of twenty new menu rows.

## Fixes

The item is still visible. It is a handler this editor does not own. Use a shell-extension list.  
Restore does not bring a command back. The parent program removed it, or you need a sign-out. Reinstall the parent if the command was its feature.  
A new shortcut does nothing. The target Windows tool is missing on that edition. Remove the shortcut.  
The menu became enormous. Restore, then add a single command.  
Changes vanish after an update of the vendor app. The app rewrote its verb. Reapply your one removal or uninstall the app.

## A Smaller Menu Is the Win

The useful edit is one command removed or one command added, with the restore point the tool keeps still available. A menu that lists every utility Sordum can insert is harder to use than the vendor clutter you started with. On a PC you do not own, remove the leftover item you were asked about and add nothing.

If a vendor update puts the item back, the program is repairing its own verb. Hiding it again is fine. Uninstalling the program is better when nobody wants it. Easy Context Menu will not stop that installer from writing the verb on the next launch.

| Edit | Keep it |
|---|---|
| One leftover command removed | Yes |
| A copy-path item you use weekly | Yes |
| A page of new admin shortcuts | No, unless this is your own PC |
